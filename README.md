# 🎄 Projeto Escolar de Natal

Site web multi-páginas desenvolvido com HTML5 e CSS puro para a disciplina.

## 📄 Conteúdo do Site

- **Home (`index.html`)**: Apresentação e textos explicativos.
- **Tradições (`pages/tradicoes.html`)**: Costumes natalinos e tabela informativa.
- **Cardápio (`pages/cardapio.html`)**: Pratos típicos e formulário de encomenda.

## 🛠️ Tecnologias

HTML5, CSS3 (Flexbox e fontes customizadas) e controlo de versões com Git/GitHub.
